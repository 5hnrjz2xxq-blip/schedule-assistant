# 宜宾学院课程表工具

一个用于提取和导出宜宾学院课程表的iOS SwiftUI应用。

## 功能特性

1. **WKWebView集成** - 加载学校e-hall登录页面
2. **安全登录** - 支持学号密码登录，验证码由网页原生处理
3. **课程数据提取** - 使用JavaScript注入从网页表格提取课程数据
4. **智能解析** - 解析课程名称、教师、地点、时间等信息
5. **日历导出** - 生成标准.ics文件，可导入Apple日历
6. **复杂周次支持** - 支持如"2-3周,5-17周(单)"的复杂周次格式
7. **多时段课程** - 支持5-8节等跨时段课程
8. **课程列表展示** - 清晰的课程列表视图

## 技术实现

### 1. WebView集成
- 使用WKWebView加载学校登录页面
- 支持JavaScript注入提取表格数据
- 监听页面导航事件，自动检测登录状态

### 2. 数据提取
- JavaScript脚本从HTML表格提取原始课程数据
- 支持colspan和rowspan的正确处理
- 提取课程代码、名称、教师、地点、时间等信息

### 3. 课程解析
- 支持多种课程格式
- 解析复杂周次规范（单周、双周、多范围）
- 处理多时段课程（如5-8节拆分为5-6节和7-8节）

### 4. 日历生成
- 生成标准ICS格式文件
- 包含亚洲/上海时区信息
- 为每门课程的每个上课日期创建独立事件
- 事件包含课程名、地点、教师、时间等详细信息

## 使用方法

1. **登录**
   - 启动应用，WebView自动加载登录页面
   - 输入学号和密码
   - 完成验证码验证
   - 点击登录

2. **提取课程**
   - 登录成功后，应用自动导航到课程表页面
   - 点击"提取课程"按钮
   - 等待数据提取完成

3. **查看课程**
   - 提取完成后，课程列表显示在底部
   - 可查看每门课程的详细信息

4. **导出日历**
   - 点击"导出日历"按钮
   - 生成.ics文件
   - 通过分享菜单导入Apple日历

## 时间表配置

宜宾学院时间表：
- 1-2节: 08:20-10:00
- 3-4节: 10:20-12:00
- 5-6节: 14:00-15:40
- 7-8节: 16:00-17:40
- 5-8节: 14:00-17:40（跨时段课程）

学期开始日期：2026年3月2日（星期一，第1周）

## 周次格式支持

应用支持以下周次格式：
- `1-16周` - 连续周次
- `2-3周,5-17周(单)` - 多范围，单周
- `2-18周(双)` - 双周
- `1-8周,10-16周(单)` - 复杂组合

## 注意事项

1. 首次使用需要连接网络
2. 登录信息存储在WebView中，不会保存到本地
3. 生成的ICS文件保存在应用沙盒目录
4. 导出的日历事件包含完整的课程信息
